# Wallpaper Carousel

Локальное расширение GNOME Shell для выбора обоев из галереи в верхней панели.

UUID: `wallpaper-carousel@d4n1ss1m0`. Совместимые версии GNOME Shell указаны в `metadata.json`.

Каталог используется проектом `../gnome-setup` как источник файлов при `apply`. Перед применением всего снимка проверьте список изменений командой `../gnome-setup/scripts/gnome-setup apply --diff`. После обновления установленной копии перезагрузите расширение в сеансе GNOME. Перед изменениями прочитайте `AGENTS.md`.
